Yayınlama: GitHub'da herkese açık vize-hocam deposu oluştur. Bu klasördeki dosyaların tamamını depo ana dizinine yükle. Depoda Settings > Pages bölümüne gir; Build and deployment kısmında Deploy from a branch seç, branch olarak main ve klasör olarak /(root) seçip Save'e bas. Yayınlama tamamlanınca GitHub bir site bağlantısı gösterecek.

iPhone: yayımlanan bağlantıyı Safari'de aç > Paylaş > Ana Ekrana Ekle.
Android: Chrome'da aç > menü > Uygulamayı yükle / Ana ekrana ekle.

VTYS bilgilendirme notu uygulama içinde ders seçildikten sonraki ekranda görünür.
